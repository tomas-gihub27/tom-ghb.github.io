O mně

Vývoji webových aplikací se věnuji již více než 4 roky. Fascinuje mě propojení technologií a designu – tvoření rozhraní, která nejen skvěle vypadají, ale především bezchybně fungují.

V současné době se zaměřuji primárně na React ekosystém a moderní CSS frameworky. Rád optimalizuji výkon aplikací a dbám na čistou architekturu kódu. Když zrovna nekóduji, pravděpodobně čtu o nových technologiích nebo piju dobrou kávu.

Technologie, které používám:

JavaScript (ES6+) TypeScript React.js Next.js HTML5 & CSS3 Tailwind CSS SASS/SCSS Git & GitHub Figma REST APIs Node.js (Základy)
